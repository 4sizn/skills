# 렌더링 산출물 캡처

문서, PDF, 슬라이드, 스프레드시트와 정적 디자인은 편집 소스가 아니라 최종 렌더링 또는 내보낸 자산을 증명한다.

## 결과물별 경계

- 문서·PDF: 최종 페이지 렌더를 캡처한다. 페이지 구조가 중요하면 관련 페이지를 모두 확인하고 대표 페이지를 증거로 제시한다.
- 슬라이드: 편집기 구조가 아니라 실제 슬라이드 렌더나 발표 화면을 캡처한다.
- 스프레드시트: 사용자가 보는 시트, 표, 차트와 필요한 계산 결과가 함께 보이는 화면을 캡처한다.
- 정적 이미지·포스터·아이콘: 최종 내보낸 파일 자체를 이미지 열람 도구로 확인하고 증거로 표시한다.

## 확인 항목

- 페이지 또는 캔버스 크기, 방향과 여백
- 글꼴 대체, 줄바꿈, 잘림, 오버플로와 겹침
- 이미지, 차트, 표, 수식과 필수 텍스트의 누락 여부
- 여러 페이지·시트·슬라이드 사이의 일관성
- 빈 페이지, 숨은 오류 표시와 내보내기 실패 흔적

구조 검사나 텍스트 추출은 보조 검증일 뿐, 최종 렌더의 눈검증을 대체하지 않는다.
